# BlocusRP Stats

This project includes scripts to save and display player stats persistently in a Roblox game. It handles saving and loading player data using Roblox's DataStoreService, creating leaderstats for each player, and displaying their stats (stars and trophies) on the screen. The system ensures that player stats are saved when they leave the game and loaded when they rejoin.

## Install

1. Download the project files from GitHub.
2. Place the `DataManager.server.lua` script in the `ServerScriptService` folder of your Roblox game.
3. Place the `StatsDisplay.client.lua` script in the `StarterPlayerScripts` folder of your Roblox game.

## Use

1. The system will automatically handle saving and displaying player stats.
2. Player stats (stars and trophies) will persist between game sessions.
3. A GUI will display the player's stats on the screen.
